# FDE capstone starter: Northwind Parcel

A realistic client case for the **Module 9 capstone**. Complete it end to end and you will have lived the whole forward deployed engineer cycle: discover, explore, decide, prototype, validate, iterate, own.

Needs Node 18 or newer. No packages to install.

## Start

```
npm test          # 3 tests, all pass today (that does not mean the report is right)
npm run report    # the legacy report nobody trusts
```

1. Read `CLIENT_BRIEF.md`. It is the whole request, as the client wrote it, plus the notes from your first conversations.
2. Read `ROLES.md` and pick your role: developer, ops, QA or engineering lead.
3. Follow the seven assignments in the academy (Module 9). Each one asks for a specific piece of evidence.
4. Copy this folder out of the academy repository before you start, and work in your own copy.

## Files

- `CLIENT_BRIEF.md` the client email and your interview notes
- `ROLES.md` what each role hands in
- `data/shipments.csv` the latest weekly export, as messy as a real one
- `legacy/report.js` the existing report
- `test/legacy.test.js` tests for the legacy report
- `ANSWERS.md` mentor answer key. Do not open it until you have written your own handover.
